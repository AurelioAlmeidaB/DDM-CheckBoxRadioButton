# CheckBox e RadioButton

App de cadastro de produto que mostra as cores e o tamanho escolhidos.

## O que o app faz

- O usuário digita o nome do **produto**.
- Marca uma ou mais **cores** (Branco, Preto, Verde) com `CheckBox`.
- Escolhe um **tamanho** (Grande, Médio, Pequeno) com `RadioGroup`/`RadioButton`.
- Ao tocar em **Enviar**, o app mostra o produto, a lista de cores marcadas e o tamanho escolhido.
- Se nenhum tamanho for escolhido, aparece "Nenhum tamanho selecionado".

Usa View Binding para acessar os componentes da tela.
